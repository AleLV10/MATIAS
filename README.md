# MATIAS
MATIAS: Matemáticas, Tecnología, Inteligencia Artificial y Aprendizaje Socrático
MATIAS es una plataforma educativa diseñada para apoyar el proceso de aprendizaje mediante herramientas digitales, gestión de contenidos y seguimiento del progreso de los estudiantes.

## Características

* Gestión de usuarios y roles.
* Administración de cursos y contenidos.
* Actividades y evaluaciones.
* Seguimiento del progreso.
* Retroalimentación al estudiante.
* Asistente educativo.

## Tecnologías

* HTML
* CSS
* JavaScript
* Git / GitHub
